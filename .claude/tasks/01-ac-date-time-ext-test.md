# Задача 1: Тесты для ACDateTimeExt

**Приоритет:** Высокий
**Зависимости:** Нет
**Исходный файл:** `lib/src/utils/src/ac_date_time_ext.dart`
**Тестовый файл:** `test/utils/ac_date_time_ext_test.dart`

## Тест-кейсы

- `equalToDay()` возвращает `true` для одинаковых дат с разным временем
- `equalToDay()` возвращает `false` для разных дней
- `equalToDay()` возвращает `true` для идентичных дат
- Граничный случай: сравнение полуночи `00:00` и `23:59` одного дня

## Указания

- Чистый Dart, зависимость только от `package:test`
- Extension-метод на `DateTime` — импортировать из исходного файла

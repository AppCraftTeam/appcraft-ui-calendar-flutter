# Задача 2: Тесты для ACDateRange

**Приоритет:** Высокий
**Зависимости:** Нет
**Исходный файл:** `lib/src/domain/src/ac_date_range.dart`
**Тестовый файл:** `test/domain/ac_date_range_test.dart`

## Тест-кейсы

- `clampDate()` — дата внутри диапазона возвращается без изменений
- `clampDate()` — дата до `min` возвращает `min`
- `clampDate()` — дата после `max` возвращает `max`
- `clampDate()` — дата равна `min` / `max` — возвращается как есть

## Указания

- Чистый Dart, без Flutter-зависимостей
- Проверить поведение `clampDate` на граничных значениях
